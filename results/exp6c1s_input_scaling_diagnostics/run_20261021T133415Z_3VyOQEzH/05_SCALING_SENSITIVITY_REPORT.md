# Exp6C-1S 输入缩放敏感性诊断（没有训练）

本轮只验证：固定A1 best checkpoint在train-only固定样本上，输入缩放是否缓解首次/后续投影截断，并保留有限可传递的辅助梯度。This result verifies only the declared computational claim under the recorded environment and protocol.
不把接近边界视为错误，不强迫固定标签向量靠近球心。模型eval/FP32，gamma0.1、c1、label vectors和所有参数不变；未新增训练、seed或Test，也未评估新的Validation/Test成绩。
同上次10个固定cohort，每组16条，160个位置、145个独立train IDs。尺度预先固定1、0.3、0.1、0.03、0.01；不是搜索识别成绩。pooled表对重复ID按固定cohort顺序首次出现去重，完整逐cohort/逐样本数据仍保留。

## 1. 真实执行位置
A1Model.forward -> hyper.encode(h) -> HNN.encode -> proj(expmap0(proj_tan0(h,c),c),c) -> HypLinear -> HypAct。新模型对象上临时仅把进入hyper.encode的h替换为s*h；原manifold方法原样调用，并记录传入/传出范数。参数和原始源码不修改，所有临时属性在finally中还原。
HNN调用encode/layers.forward会绕过普通nn.Module __call__ hooks，因此记录器观察原manifold.expmap0/proj/mobius_matvec/mobius_add/logmap0调用，包含HypLinear的矩阵乘、bias、Möbius加法和HypAct重映射。bias与text分开计数。
c=1时原FP32投影cap约0.996；首次未截断时半径为tanh(s*||h||)，截断条件为tanh(s*||h||)>cap。理论阈值为s*||h||>atanh(cap)≈3.1063；||h||≈22时约s>0.1412。实际是否后续重新推到边界由事件表判断，不能只依据该公式。

## 4. 解释与停止边界
首次截断减少的预设尺度：[0.1, 0.03, 0.01]。其中仍出现后续text投影clip的尺度：[0.1]；须结合各stage/最终分布判断改善是否保留，不只看首次expmap。
g_BCE是全部27类BCE对共享参数的梯度；g_aux是0.1×aux对共享参数的梯度。表中是当前checkpoint、eval状态、定向样本处的局部几何干预，不代表训练所有步，也不代表单个情绪那一列的梯度。h梯度另有径向/切向分解；分类头的aux不连接、额外分支的BCE不连接属于设计。
scale=1必须与无instrumentation前向逐元素相同，并复现Exp6C-1D同cohort的Loss/梯度。所有s的正式分类logits与BCE应完全相同；因为权重未更新且分类路径不经过辅助分支，这个静态检查本来就不能令grief F1恢复。
降低clip且梯度有限，只支持继续评估一个预注册单因素训练候选，不证明尺度为最优或将提升Macro/Rare-F1；已有权重是在s=1下训练，其他s是分布干预，不能用哪个aux更低来选识别模型。不会自动批准训练或启动多seed。
本次结果不隔离双曲几何独立价值，未来仍需匹配的Euclidean Control。固定标签向量不缩放、不移动；gamma、曲率、expmap/proj/decoder实现、分类器和阈值均不改。
源文件/参数/buffer前后hash、RNG状态、构造环境、全部固定IDs、原始逐stage范数、每尺度z/decoder logits等缓存均归档；旧A0/A1/Exp6C-1D输入哈希在诊断前后复验。

## 导师汇报要点
本轮是几何可行性诊断，不是性能实验。先回答缩放是否减少强制截断，以及HNN后续是否又把点推回边界；正式训练和多seed都暂缓，等待完整诊断结果审阅。
