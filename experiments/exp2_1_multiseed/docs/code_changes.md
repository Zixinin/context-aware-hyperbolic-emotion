# Experiment 2.1 orchestration changes

This release leaves the original BERT, LGSA adapter, working parent-map patch and frozen upstream source untouched. `frozen/expected_sources.json` pins their exact file-level source identities. Mathematical training loops are imported from the already validated HPC projects.

1. **BERT:** call the original `src.train.run(config, output_dir)` with a deep-loaded frozen config whose only scientific change is the requested seed. The new shared infrastructure smoke gate replaces the old CLI gate that unnecessarily demanded a same-seed smoke for every full run. The original `run()` itself is unchanged. A `load_model` wrapper compares raw backbone tensors before training and permits only the selected same-run checkpoint for subsequent reload.
2. **LGSA:** call original `run.train()` unchanged. Bind that module's imported `config()` to the per-run config so that its existing `loader()` shuffle and generator use the same seed as model initialization. Call the original seed function and explicitly repeat CUDA/Transformers seeding without consuming random samples or changing deterministic flags.
3. **LGSA initialization reference:** intercept only `digest_state` after raw-backbone/HGS construction in an initialization-only process. After the second digest, exit before optimizer/training. The full process uses the original full-run fingerprint assertions against this same-seed fresh reference. No trained weights are transferred. No optimizer state is loaded.
4. **LGSA reporting only:** disable the legacy post-run comparison against a fixed BERT42 reference. The new aggregator instead compares seed42 vs42,123 vs123,2026 vs2026. This happens after training/evaluation and does not affect any gradient, output logits or checkpoint selection.
5. **Scheduler:** a single GPU allocation serializes the smoke stage, missing BERT runs, and missing LGSA runs. The CPU report job uses `afterok`, then checks all relevant main/batch/extern accounting records and artifact gates. Exceptions produce nonzero exits. Runs have unique job/model/seed paths, and submission is locked against accidental duplicates.
6. **Logging/derivation:** record code release commit/hashes, actual runtime flags, parameter fingerprints, peak GPU memory, phase runtime, model/source/config identities. Standardize legacy outputs into new directories; preserve native original checkpoint paths and hashes. Recompute TP/FP/FN and both threshold reports only from saved predictions. Preserve BERT float64 sigmoid and LGSA float32 sigmoid to avoid changing boundary decisions.

Preserved details include partial-batch gradient normalization in BERT, optimizer parameter groups, Adam versus AdamW, warmup ceil versus floor, FP32, evaluation batch sizes, text/prompt lengths, HGA ramp, hierarchy mapping, HGS/HGA geometry settings, validation checkpoint selection and threshold tie rules. Native LGSA diagnostic plotting remains unchanged because it can consume NumPy RNG; it is not removed or moved into the training loop.

No loss ablation, Hyperbolic model, new hierarchy, training extension, per-label threshold, class reweighting or test-set tuning is introduced.
